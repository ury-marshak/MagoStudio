## Availability and startup

- `src/platform/modelProviders.ts`, `providerPreferences.ts`, and `renderTarget.ts` resolve renderer model availability. The cloud route incorporates Mago account state. The existing location flags also affect submission and asset handling. Keep external provider availability separate from those flags.
- `desktop/shared/textModelRoute.ts` retains signed-out legacy routing behavior. Desktop external text selection is separate and must surface configured-provider failures without silently switching to Mago or ComfyUI.
- Director fal actions bypass local model readiness checks. With any external-provider metadata entry present, omitted text/vision capabilities now fail explicitly; legacy Comfy rendering, model probes, launch/setup and downloads are gated in the main process. General editor UI availability, broader renderer traffic and in-flight configuration changes remain audit gaps.
- Director external actions have provider-specific availability and cost labels. Legacy sign-in, credit recovery, and ComfyUI setup UI still exist outside the supported subset; audit those paths before claiming complete independence.
- Account-free startup, editing, and the supported Director workflow passed packaged checks. Startup/background requests and main-process plus renderer network traffic still need a complete audit. Prior log inspection alone does not prove independence.

### Account-free supported-route trace and validation boundary

1. Isolated provider metadata → `resolveProviderStartupMode(null, settings)` → offline/local identity → no Clerk/backend provider, maintenance poll, Product Fruits, cloud watcher or sync effect. Explicit saved cloud mode is intentionally different.
2. Script/chat/cast/compose → local prompt assembly → configured text HTTPS transport. Reference descriptions/metrics/captions → configured vision transport, or explicit unavailability when omitted; never resolve an omission to legacy inference.
3. Director references/storyboards → selected fal model; shots → durable prepared request → saved typed uploads/submission → immutable job polling/output ingestion → local Timeline/export. Preserve all audited session and uncertain-submission guards.
4. Startup still creates the legacy image-render service, but its injected gate pauses reconciliation/polling before DB writes, endpoint access or network. Historical Comfy endpoints saved in requests cannot bypass this check.

Policy: the presence of any text, vision or fal entry in `external-providers.json` disables these **legacy inference/setup entry points**, including a saved `local-comfy` shot preference. Missing/empty metadata preserves legacy behavior; removing every external entry restores it. Invalid entries are never permission to fall back. This is metadata-only, independent of credential readiness and Mago identity. It is not a global network firewall: deliberately saved cloud mode, historical cloud storage URLs and unreviewed renderer/backend calls remain distinct audit gaps.

Mocked evidence: `application.independence.test.ts` exercises composed main startup for three isolated no-credential partial profiles, including a saved Comfy job; Node fetch, HTTP(S) request, WebSocket, Electron net.fetch and child-process/Keychain traps remain unused. `providers/externalInferenceRouting.test.ts` exercises omissions, automatic-caption suppression, configured-provider errors and an exact selected-provider POST. `ipc/externalInferenceGates.test.ts` covers local supporting/setup gates; `imageRenders/externalInferenceGate.test.ts` preserves seven-model queues in real temporary SQLite libraries. No usable keys, live inference, existing profiles or packaged bundles are used. The main startup harness fakes BrowserWindow loading, so renderer-wide traffic and a combined Director transport trace remain next.

The OpenAI-compatible adapter supports deadlines and caller signals. Director casting and shot composition propagate plan cancellation. Renderer caption/AutoPrompt/enhancement/adaptation requests use opaque IDs with trusted sender-scoped cancellation; teardown aborts them, shared captions retain independent consumer ownership, and cancelled responses cannot trigger repair or persistence. Script chat supports explicit turn/project cancellation, shutdown and chat-specific library teardown; it repairs only malformed responses, not transport failures. Chat database operations drain before library replacement; IPC is session-bound and late responses cannot write into a replacement library. ## Try the initial text and vision adapter on macOS

1. In Keychain Access, create a password item in the login keychain. Set the item name to `MagoStudio.ExternalProvider`, the account to a name such as `openrouter`, and the password to the API key. Grant access if macOS prompts when Mago first reads the item.
2. Open **Local settings → Providers**. For text, vision, or both, enter the API base URL, an exact model ID from the provider's catalog, and the Keychain account name. Use the same account in both entries to share a key. For OpenRouter, you can set **Reasoning effort** independently for text and vision. Choose **Provider default** to omit the effort setting.
3. Save each entry, then use **Check connection** to look up its model. OpenRouter also checks the saved key and, for vision, image input support. The check makes no generation request.

You can also edit `external-providers.json` alongside the app-level `settings.json`, typically in `~/Library/Application Support/Mago Studio/` for the packaged app. Use the profile directory of the instance you are running and keep API keys in Keychain.

```json
{
  "text": {
    "baseUrl": "https://openrouter.ai/api/v1",
    "model": "openai/gpt-6.1-terra",
    "reasoningEffort": "low",
    "keychainAccount": "openrouter"
  },
  "vision": {
    "baseUrl": "https://openrouter.ai/api/v1",
    "model": "openai/gpt-6.1-terra",
    "reasoningEffort": "low",
    "keychainAccount": "openrouter"
  }
}
```

Vision covers desktop descriptions, captions, AutoPrompt, and shot evaluation. Text covers desktop script chat, image prompt enhancement, the local branch of video prompt optimization, and casting and shot prompt composition for locally managed Director projects. Cancelling a plan aborts its active external text request. A failed external shot prompt pauses the plan before video submission. Desktop prompt optimization displays the external route and uses local asset IDs for video prompt optimization. Local Director chat and casting can pass the text access check without a Mago sign-in or ComfyUI text model. The first-launch choice can be skipped when valid external-provider settings are already present. A fresh profile with valid provider settings opened the local editor in the packaged Apple Silicon app. Live prompt enhancement and image captioning passed with GPT-6.1 Terra at Low reasoning effort. When any external-provider entry is present, an omitted text or vision capability is explicitly unavailable rather than routed to Mago/ComfyUI. Automatic captions skip omitted vision without a legacy readiness probe. Errors from a configured capability are surfaced without switching providers. Legacy inference/setup remains available only in profiles with no external entries; this is not a promise that all other app network entry points are gated.

The adapter expects an HTTPS API with non-streaming Chat Completions and `max_completion_tokens`. Vision requests send up to four inline PNGs.
